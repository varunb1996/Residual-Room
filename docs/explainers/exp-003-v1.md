# Why retrieval fails: chunking, lost context, near-duplicates

Series: Failure Modes · Segment: practitioners · ID: exp-003 · Version: v1 · Published: 2026-11-03
Status: superseded by exp-003-v2 on 2026-11-10 (kept per the corrections policy; contains a seeded error)

## The problem
A RAG pipeline can retrieve the right document and still produce the wrong answer. Most of these failures happen before the model reads a single token: in how the text was split, where the evidence lands in the prompt, and what else was retrieved alongside it.

## Failure 1: chunking cuts the evidence
Text splitters work on characters or tokens, not meaning. LangChain's recursive splitter, for example, tries a list of separators in order (paragraphs, then sentences, then words) until each chunk fits the size limit [cite:ext-langchain-splitters]. We think the most common symptom is a definition or a table split across two chunks: retrieval returns one half, and the answer is confidently built on it.

## Failure 2: the evidence lands in the middle
Liu et al. found that models use information best when it sits at the start or end of the context, and that accuracy drops when it sits in the middle, even for models built for long contexts [cite:ext-litm-paper]. Adding more retrieved documents stopped helping well before the retriever stopped finding relevant ones [cite:ext-litm-paper]. Lost in the Middle tested only GPT-3.5-Turbo, so treat the result as specific to that model.

## Failure 3: near-duplicates crowd out the evidence
If a corpus holds several near-identical copies of a page (old versions, mirrors, templated docs), top-k retrieval can fill every slot with copies of one passage. We think this is the most under-diagnosed of the three, because each retrieved chunk looks relevant on its own.

## How to detect them
- Log chunk boundaries next to retrieved text, and read a sample of misses.
- Move the gold passage to different positions in the prompt and compare accuracy.
- Count distinct sources in the top-k results, not just relevance scores.
